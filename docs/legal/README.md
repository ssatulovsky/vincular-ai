# Documentos legales y clínicos (borradores)

> **Borradores para revisión.** Los redactó el equipo de desarrollo a partir del diseño del sistema. **No son asesoría legal.** Antes de usarlos con personas reales, los debe revisar un abogado especialista en protección de datos y salud, y el equipo clínico debe validar lo marcado como `[Validar clínicamente]`.

Responsable del tratamiento: **InnovAgile Group SpA**, RUT 77.798.901-4.

| Documento | Para qué sirve |
|---|---|
| [consentimiento-informado.md](consentimiento-informado.md) | Texto en lenguaje simple para la persona mayor (y su representante), con constancia de entrega |
| [aviso-privacidad.md](aviso-privacidad.md) | Información sobre el tratamiento de datos (deber de información, Ley 21.719) |
| [registro-actividades-tratamiento.md](registro-actividades-tratamiento.md) | Registro de actividades de tratamiento: finalidades, datos, plazos, encargados y transferencias |
| [evaluacion-impacto.md](evaluacion-impacto.md) | Evaluación de impacto en protección de datos: riesgos y medidas |
| [encargados-tratamiento.md](encargados-tratamiento.md) | Proveedores que procesan datos, qué reciben y estado de cada acuerdo |
| [preguntas-psiquiatria.md](preguntas-psiquiatria.md) | Preguntas frecuentes de psiquiatras y equipos de salud mental, con la respuesta del sistema |

En el panel, la sección **Preparación del piloto** lleva el estado de cada uno de estos acuerdos.
